3.NOT
example1:
num=20

if [ ! $num -eq 10 ]
then
    echo "Number is not 10"
else
    echo "Number is 10"
fi

example2:
user="student"

if [ ! "$user" = "admin" ]
then
    echo "You are not an admin"
else
    echo "You are an admin"
fi

note:
= → compares strings
-eq → compares numbers

D.case statements

method1:
color="red"

case $color in
    red)
        echo "Red color"
        ;;
    blue)
        echo "Blue color"
        ;;
    green)
        echo "Green color"
        ;;
    *)
        echo "Unknown color"
        ;;
esac


method2:
choice=2

case $choice in
    1)
        echo "Start"
        ;;
    2)
        echo "Stop"
        ;;
    3)
        echo "Restart"
        ;;
    *)
        echo "Invalid choice"
        ;;
esac

IMPORTANT BASH OPERATORS

Operator    Meaning                    Used for
----------------------------------------------------
-eq         Equal                      Numbers
-ne         Not equal                  Numbers
-gt         Greater than               Numbers
-lt         Less than                  Numbers
-ge         Greater/equal              Numbers
-le         Less/equal                 Numbers
=           Equal                      Strings
!=          Not equal                  Strings
&&          AND                        Conditions
||          OR                         Conditions
!           NOT                        Conditions
-f          File exists                Files
-d          Directory exists           Directories

B.while 

Loop    Runs when           Stops when
while   Condition is true   Condition becomes false
until   Condition is false  Condition becomes true


1. Print numbers from 1 to 5
i=1

while [ $i -le 5 ]
do
    echo $i
    i=$((i+1))
done
Output:
1
2
3
4
5


2. Countdown
i=5

while [ $i -ge 1 ]
do
    echo $i
    i=$((i-1))
done
Output:
5
4
3
2
1


3. Print multiplication table
num=5
i=1

while [ $i -le 10 ]
do
    echo "$num x $i = $((num * i))"
    i=$((i+1))
done
Output:
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
...
5 x 10 = 50
